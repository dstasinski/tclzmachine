# tclzmachine integration story fixtures

This directory contains repository-owned Z-machine games used to test the interpreter without depending on commercial Infocom story files.

## Layout

- `source/tclzmachine-test.inf` is the human-readable Inform 6 source for the standard-library integration game.
- `compiled/tclzmachine-test.z5` is the deterministic Version 5 story generated by GitHub Actions from that source.
- `source/tclzmachine-v3.inf` is a compact no-library Inform 6 source designed specifically for Version 3.
- `compiled/tclzmachine-v3.z3` is the deterministic Version 3 story generated from that source.

Both sources use fixed Inform serial numbers so recompiling unchanged source with the same toolchain does not create needless binary changes.

## Why the fixtures differ

The current Inform 6 standard library uses language features and Z-machine opcodes that require V5 or later. Inform's own documentation notes that Inform 6 can still generate V3 when the source avoids those V5-only library/language features, but the modern standard library itself cannot be used for V3.

The project therefore uses two complementary fixtures:

- the V5 story uses the current standard library and exercises a real Inform parser plus ordinary adventure-game behavior;
- the V3 story deliberately uses no standard library and directly exercises the older VM model with a small, deterministic command loop.

This avoids pretending that a modern standard-library build is V3 while also avoiding a dependency on an old or third-party V3 parser library.

## Version 5 integration coverage

The active `repository-story-integration` CTest drives commands including:

```text
look
take lamp
inventory
north
south
save
drop lamp
north
restore
look
inventory
```

These interactions exercise line input, explicit V5 tokenization, parser-driven routine calls, Z-text output, object relationships and movement, properties and attributes, persistent game state, room movement, inventory handling, ordinary control flow, and the cooperative Tcl save/restore boundary.

The persistence portion saves while the player is in Test Lab carrying the brass lamp, deliberately changes both object ownership and location, then restores the Quetzal file and verifies that Test Lab and the carried lamp return. This makes the fixture an end-to-end check of real Inform parser state plus Quetzal dynamic memory, evaluation stack, routine frames, saved PC, and Tcl file-request handling.

## Version 3 integration coverage

The active `repository-story-v3-integration` CTest drives the no-library V3 fixture through commands including:

```text
look
take lamp
inventory
save
drop lamp
north
restore
look
inventory
```

This checks the V1-V3 text-buffer format used by `sread`, V3 routine locals/calls, globals, 9-byte object records with byte-sized parent/sibling/child fields, `get_child`, `get_parent`, `insert_obj`, branching, and persistent state across separate Tcl calls.

Its persistence cycle also exercises the V1-V3 form of `save`/`restore`, where `save` is a branch opcode rather than a store-result opcode. The save occurs inside a called routine; after object and room state are deliberately changed, restore must reconstruct that routine frame and resume at the original save branch. The test verifies that both the global room state and the lamp's V3 object parent are restored.

The fixtures contain no Infocom source, text, data, or other commercial story content. Official Infocom games may be used separately for local compatibility testing but must not be committed to this repository.

## Rebuilding

Normal development does not require Inform 6 locally. `.github/workflows/build.yml` installs the Ubuntu `inform6-compiler` and `inform6-library` packages, rebuilds both fixtures, and commits changed binaries back to `Frobnost` on direct pushes.

A local equivalent is:

```sh
sudo apt install inform6-compiler inform6-library

library_file="$(dpkg -L inform6-library | grep -E '/Parser(\.h)?$' | head -n 1)"
library_dir="$(dirname "$library_file")"
mkdir -p tests/games/compiled

inform6 -v5 "+include_path=${library_dir}" \
  tests/games/source/tclzmachine-test.inf \
  tests/games/compiled/tclzmachine-test.z5

inform6 -v3 \
  tests/games/source/tclzmachine-v3.inf \
  tests/games/compiled/tclzmachine-v3.z3
```

The committed binaries are what normal CTest uses, so developers do not need Inform installed merely to run the end-to-end regressions.
