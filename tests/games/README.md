# tclzmachine integration story fixtures

This directory contains repository-owned Z-machine games used to test the interpreter without depending on commercial Infocom story files.

## Layout

- `source/tclzmachine-test.inf` is the human-readable Inform 6 source for the standard-library integration game.
- `compiled/tclzmachine-test.z5` is the deterministic Version 5 story generated by GitHub Actions from that source.
- A separate Version 3 fixture remains planned and will use a library/toolchain that genuinely supports V3.

The source intentionally uses a fixed Inform serial number so recompiling unchanged source with the same toolchain does not create needless binary changes.

## Why the main fixture is V5

The current Inform 6 standard library uses language features and Z-machine opcodes that require V5 or later. The Inform 6 documentation explicitly notes that the modern standard library cannot be used for V3; V3 source must use an older or alternative V3-capable library. The project therefore builds the full parser/library integration fixture as V5 rather than generating a misleading or invalid `.z3` file.

A smaller V3-specific fixture will be added separately so tclzmachine still has repository-owned integration coverage for the older VM layout without coupling the ordinary test build to an incompatible library.

## Purpose

The test adventure is deliberately small and predictable. The active `repository-story-integration` CTest drives commands including:

```text
look
take lamp
inventory
north
south
save
drop lamp
north
restore
look
inventory
```

These interactions exercise line input, explicit V5 tokenization, parser-driven routine calls, Z-text output, object relationships and movement, properties and attributes, persistent game state, room movement, inventory handling, ordinary control flow, and the cooperative Tcl save/restore boundary.

The persistence portion saves while the player is in Test Lab carrying the brass lamp, deliberately changes both object ownership and location, then restores the Quetzal file and verifies that Test Lab and the carried lamp return. This makes the fixture an end-to-end check of real Inform parser state plus Quetzal dynamic memory, evaluation stack, routine frames, saved PC, and Tcl file-request handling.

The fixture contains no Infocom source, text, data, or other commercial story content. Official Infocom games may be used separately for local compatibility testing but must not be committed to this repository.

## Rebuilding

Normal development does not require Inform 6 locally. `.github/workflows/build.yml` installs the Ubuntu `inform6-compiler` and `inform6-library` packages and rebuilds the V5 fixture automatically. On a direct push to `Frobnost`, the workflow commits the compiled `.z5` back to the branch only when its bytes have changed.

A local equivalent is:

```sh
sudo apt install inform6-compiler inform6-library
library_file="$(dpkg -L inform6-library | grep -E '/Parser(\.h)?$' | head -n 1)"
library_dir="$(dirname "$library_file")"
mkdir -p tests/games/compiled
inform6 -v5 "+include_path=${library_dir}" \
  tests/games/source/tclzmachine-test.inf \
  tests/games/compiled/tclzmachine-test.z5
```

The committed binary is what normal CTest uses, so developers do not need Inform installed merely to run the end-to-end regression.
